# My Learning Journey

This repository is a personal learning portfolio showcasing front-end web development projects, UI design experiments, and AI-focused study notes. It brings together practical build work and conceptual learning into one place while improving my understanding of React, Vite, modern UI design, and AI-powered application concepts.

## Overview

The projects in this repository reflect a journey from beginner web development to more advanced front-end and AI-driven application thinking. Each folder contains a project or module that focuses on a different skill area, ranging from building responsive landing pages to understanding AI foundations and real-world AI app design.

## Projects Included

### 1. AI Fullstack

Path: `01-AI Fullstack/01-Introduction`

This section focuses on AI and fullstack fundamentals, including:

- `01-Netflix Clone` — a Netflix-inspired UI built with React and Vite
- `02-AI Foundations` — notes and concepts covering core AI ideas and foundations
- `03-AI-powerd Apps` — learning material about AI-powered applications and practical usage patterns

### 2. Find Your Home

Path: `Find-your-Home`

A modern real-estate landing page designed to showcase properties, highlight key benefits, introduce agents, and help users reach out quickly. It is built with React and uses reusable component-based architecture.

### 3. Portfolio Website Design

Path: `Portfolio-Website-Design`

A portfolio website concept designed to present personal work, skills, experience, and contact information in a polished, professional layout.

## Getting Started

To run any project locally:

```bash
git clone https://github.com/HudaCodeHub/my-learning-journey.git
cd my-learning-journey
```

Then navigate to a project folder and install dependencies:

```bash
cd "Find-your-Home"
npm install
npm run dev
```

Or for the Netflix clone project:

```bash
cd "01-AI Fullstack/01-Introduction/01-Netflix Clone"
npm install
npm run dev
```
